# Runtime 工作概览交付（2026-11-18）

Runtime 现在可以查看本工作台正在执行、排队和待处理的工作，以及绑定成员和历史记录。入口仍为「Runtime → 电脑 → Runtime」，本机 Web 和 API 已加载本轮实现。

## 页面与操作

- 电脑目录保留连接状态、搜索、筛选与手动命名，增加本工作台工作概况。
- 电脑详情汇总工作与成员；离线时仍可读原记录，并提供“曾使用的 Runtime”入口，明确历史记录不能证明当前安装情况。
- Runtime 详情分为「概览」「模型与能力」「工作记录」，页签写入 URL。概览展示当前工作和最近五项记录；历史每页二十项。
- 成员列表可进入执行设置或原有发消息入口。模型、推理与权限仍属于成员，Runtime 页面不修改原生全局默认值。
- 工作链接回到原聊天或收件箱单次工作，审批、停止与进度继续由原工作界面处理。展开“提交配置”读取冻结快照，不将其宣称为执行端最终采用值。
- 模型列表提供搜索、逐模型推理档位与“极速模式支持”。原来的 `priority` 是能力项，不能表示全部工作已经开启极速模式；成员可在私聊输入框通过闪电切换后续请求的 Fast 模式。移除会被误解为所有成员共用的“当前模型”标签。
- 能力及更新时间与诊断按需查看；复制仅包含设备、Runtime、版本、状态和时间等白名单字段，不复制配置文件、密钥或环境变量。

## 来源与边界

本次参考 Multica 的机器/Runtime 信息分层、当前工作和使用者组织方式，以及旧 Hutian 的执行入口与历史工作关联；按当前 Hutian 成员配置归属实现，没有搬入对方的调度、云资源或并发管理。参考产品索引见根目录 `docs/development-references.md`。

新增 API `runtimes.overview` 是现有聊天请求和定时运行的只读投影，按当前工作空间、用户及 Dock 接入来源过滤，未新增执行账本或迁移数据。页面统计仅覆盖本工作台已记录的工作，不代表设备上的全部原生会话。状态来自现有协调记录，可能需要同步；活跃概览在可见时每十五秒刷新，历史页不自动重置分页。

额度、费用、Token 和套餐余额没有可靠数据来源，本轮不展示估算。没有新增全局模型开关、安装/重启按钮、云实例管理或自动调度。图片能力展示接口报告，同时提示逐模型限制。

初次交付时 ZCode Flash 推理档位补丁因活跃工作未重载。随后处理用户反馈的旧运行待核对问题，在确认设备空闲后重载后台；历史最终回答和成果沿原记录补回，详见 [ZCode 接入记录](zcode-runtime-2026-11-18.md)。

## 实际验收

- 共享契约构建、API/Web 类型检查、API/Web 构建及本轮页面组件 ESLint 通过；没有新增永久测试、框架或依赖。
- 真实浏览器核对电脑目录、三种 Runtime 页签、模型搜索、成员设置链接、原聊天/定时工作链接、提交配置展开和诊断复制。
- Codex 历史按 20/20/20/20/20/5 分页读出 105 条，去重后仍为 105 条，游标正常结束。不存在的设备返回空工作与成员；无效游标返回 400。
- ZCode 概览实际显示进行中、排队、待核对各一项；没有重发或取消这些工作。
- 当前 Windows 离线时，仍保留 11 条原工作记录和曾使用的 Runtime 入口；未修改 Windows 安装、配对或权限。
- 1440px 桌面与 390px 窄屏实际浏览检查通过；概览、模型页和目录无横向溢出，浏览器无 pageerror。
- API 通过原 launchd 管理命令重载，Web 使用构建脚本原子更新静态资源；原执行宿主与 Dock 进程保持运行，没有重新配对或触发新的模型调用。
