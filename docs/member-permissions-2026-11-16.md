# 成员执行权限

2026-11-16，第 7 段增量，保持未提交。

成员 → 设置 → 执行配置，在推理等级下面选择「执行权限」并保存。默认跟随执行端，具体选项来自所选 Runtime 的原生权限能力；当前本机 Codex 报告只读、工作区访问、自动审查、完全访问四种模式。中文名称仅为展示映射，不据此给其他 Harness 补造能力。没有报告选项时明确提示，仅保留跟随执行端；离线、读取失败、原选择已不可用均保留可见反馈。

权限属于成员，影响之后的私聊和群聊。私聊模型快捷修改保留已有权限值，群聊输入框不增加配置面板。更换 Runtime 清空原执行偏好，重新选择。独立定时安排保留原配置，执行端全局设置不改动。

配置写入原 `role_runtime_bindings.preferences` JSONB，不需要数据库迁移。保存与派发均核对实时能力；权限在工作快照中以 `config.mode` 传给 Matrix 宿主和 Dock。跟随执行端且已报告当前模式时，在提交时冻结该模式。已有工作及恢复原运行不重新读取成员偏好。Dock 原生适配器负责设置和核对实际模式，失败时不降级到其他权限。保存成功只表示成员配置已保存，不等于某个未来运行已确认权限生效。
