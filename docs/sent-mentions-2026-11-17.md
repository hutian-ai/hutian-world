# 群聊已发送消息的成员标签

用户反馈输入框选中的 @ 在发送后显示为普通文字。原消息正文保留可读文本，Matrix `m.mentions` 也仍保存真实点名身份；缺失的是用户消息的 Markdown 呈现。

现在以原消息明确保存的点名身份提供成员显示信息，在 Markdown 文本节点中呈现对应标签。输入框和消息正文共用设计包 `ChatMention`，保留现有绿色样式。没有修改原消息、执行请求、成员权限或点名派发规则，也不因渲染推断新的执行对象。

普通文字、行内／块级代码、链接和类似邮箱的文字保持原语义。没有原点名身份的消息不根据 @ 字面量补造点名。历史消息在身份和当前显示名可匹配时同样呈现标签；没有保存旧显示名的历史消息在成员改名后可能保持普通文字。

实际浏览器核对现有群聊中的原消息，发送后的标签与输入框选中标签的文本、样式相同；刷新后仍可见。旧标签页在前端更新后导航并刷新正常，桌面及 390px 窄屏无页面异常或横向溢出。未发送新消息或触发模型执行。原始证据只保存在 ignored `.local/mention-rendering-20261117/`。

设计包类型检查、文档构建，Web 正式构建及新增组件／解析器 lint 通过。全站 Web 类型检查最新一轮仍受到并行修改中的 Runtime 详情页缺少 ObjectHeader 必填属性、收件箱旧函数名两处错误阻塞；不是本次成员标签的类型错误。期间新增成员页存在 JSX 残片阻塞 Web 构建，已仅移除残片，保留该页导航调整。没有新增测试工程、提交或推送。
