# 第 1 段：成员、私聊、项目与运行环境

完成于 2026-11-06。在新的 hutian-world 恢复旧工作台的「成员」「私聊」与「运行环境」入口，并保留项目与跨项目角色关联。旧工程继续作为参考，不迁移旧数据。

## 现在可以使用

打开 **http://127.0.0.1:3340**，进入私聊。当前运行的是正式构建。

- 在「私聊」选择本机已有聊天对象，创建或重新打开同一会话，发送文本并在刷新后查看历史。
- 在「成员」查看创造者及已保存的持续角色，按名称或职责搜索，配置角色及查看参与项目。
- 在「运行环境」导入 Dock 应用凭据，按名称或 Dock 设备 ID 查找电脑。打开电脑后，可点 Runtime 整行查看模型和推理档位。
- 创建项目，保存目标，查看项目列表和详情，编辑项目。
- 创建持续角色，保存职责简介和设定，查看角色列表和详情，编辑角色。
- 在项目中创建角色，或添加已有角色；同一角色可参与多个项目。
- 将角色移出项目，保留角色本身与其设定。
- 按名称和描述搜索目录；刷新或重启应用后继续读取数据库中的记录。

页面保留本轮实际创建的“hutian Web”“文档与开源交付”两个项目，以及“架构研究员”“文档作者”两位角色，共三条项目关联。它们是手动录入的业务配置，没有伪造在线状态或声称已经执行任务；新安装不会自动植入这些内容。

## 实现边界

沿用 Next.js 16 / React 19 / Tailwind 4、NestJS 12 / Fastify 5、TypeORM 1 / PostgreSQL；Zod 校验输入，UnJS c12 读取私有配置。移植旧 [DESIGN.md](../DESIGN.md)、主题、shadcn 注册表配置、共享组件、品牌图及 UI 开发指引。成员采用原有表格布局，私聊采用原有全高双栏和 assistant-ui 的会话列表、历史与输入区。具体版本和接口依据见[技术说明](technology.md)。

数据库为共享 Docker PostgreSQL 实例中的独立 `hutian_world`，应用账号 `hutian_world_app`。四张业务表是 creators、projects、roles、project_roles，另有 TypeORM 迁移表。角色归属和项目归属分开保存，项目成员关系使用多对多关联。

当前是本机可信的单创造者工作台。服务端从私有配置确定创造者范围，Web Server Actions 使用服务端应用凭据调用 API；浏览器不持有它。私聊接入已有本机 Matrix Team Chat，消息留在 Matrix。聊天对象当前来自该服务已有配置，成员角色与聊天身份还未绑定。运行环境通过 Dock SDK 读取设备与 Runtime，导入的应用凭据保存在私有配置文件。当前没有成员 Runtime 绑定、任务执行、自动触发模型回复、多人登录、实时推送或记忆与知识接入。

## 自己验收

1. 打开私聊，点目录右上角「+」，选择「协作助手」。发送一条文本、刷新并重新打开同一会话，确认原消息还在。
2. 打开成员，配置一位角色并填写职责和设定，刷新确认资料仍在。
3. 在项目里选择「添加已有角色」，把同一个角色加入两个项目。到成员详情查看参与项目；移除关联后，成员和设定仍在。
4. 打开运行环境，选择在线电脑查看其 Runtime。要连接另一个 Dock Server，点「更换连接」并导入对应的应用凭据。
