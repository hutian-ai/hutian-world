# 第 2 段：沟通、Runtime、知识与记忆核心链路

2026-11-13。用户要求本周看到 MVP，先实现六条核心链路，项目管理后置。第一段已单独本地提交为 `84eba96`；本段保留未提交 diff。

## 当前可以使用

打开 **http://127.0.0.1:3340/chat**。

- 沟通目录统一显示私聊、群聊和频道，支持搜索、新建与邀请已接入的助手。相同对象的私聊沿稳定别名复用原房间；频道用于邀请制长期主题讨论。
- 输入区明确选择只发送消息，或请某位助手处理。执行前明确选择当前 Dock 中可用的 Runtime，不隐式调用旧聊天室的默认服务。
- 回复对象、Runtime 与资源开关可保留为当前浏览器的会话偏好；每次执行仍由服务端核对，不把浏览器偏好当成正式角色绑定或授权。
- 可按需启用知识库与记忆检索，将实际命中的片段与出处传给本次执行。不是每条消息全量注入全库，也不自动触发记忆写入。
- 助手回复回到原 Matrix 房间，消息旁可展开原运行状态；未知结果保留原请求，不自动重派。网页重开从服务端读取原消息与运行关联。
- 知识库可添加 Markdown、持久保存原文、建立索引、检索并打开来源原文。索引未知时不声称已可检索。
- 记忆可明确保存偏好与决定，提交异步整理、观察原操作，并检索 / 查看对应来源。使用工作台独立的可撤销凭据，只授权本段资源。

## 技术与边界

沿用旧 hutian 主栈与设计系统。通信使用 Matrix Agents Chat，执行继续使用 Harness Dock，记忆使用 Scoped Memory Access / Hindsight，资料使用 AnythingLLM 的独立空间和接入保存的原文。凭据只放在服务端私有文件，不传入浏览器或模型材料。

当前是可信本机单创造者、文字协作 MVP。角色业务记录与 Matrix 助手的正式绑定尚未完成；当前执行入口使用通信模块已有助手配置。工作台知识和记忆不是多人或角色私有资源授权的替代实现。

当前会话页读取最近 100 条文本消息，宿主上下文最多使用最近 30 条并限制长度；它们不代表完整历史已删除，也不等于原生 session 已迁移。原生审批 UI、进行中追加 / 取消、附件、资料编辑删除、完整分页与多人登录随后按真实使用补齐。

没有新增测试代码、框架、fixture 或 CI。相关编译与正式构建通过，真实使用结果与未覆盖范围分别记录。没有推送、公开开源、npm / Release 或 X 发布。
