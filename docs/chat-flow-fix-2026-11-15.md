# 聊天交互修正与真实验证

用户在完整录屏复审后授权一起修正，并指定本轮优先对齐 agentes.chat。改动保持未提交，没有推送或发布，没有新建测试工程。其他并行工作的 API／SPA 重构不算作本轮交付。

## 已生效的变化

- 每个成员使用由发起消息和成员标识组成的稳定回复身份。已接受、运行中、最终消息使用相同位置；同一消息的多成员回复按点名顺序展示，刷新使用同一投影，不修改 Matrix 原事件时间。尚未开始的请求也有成员状态。
- 正常发送期间不出现“请助手处理”的恢复入口；真实缺失请求沿原消息重试。队列明确成员名称，暂停后沿原入口手动恢复。
- 私聊只保留输入区的停止入口，输入有内容时仍可停止。空输入不显示“排下一轮”菜单；有内容时可选择排队或补充当前运行。群聊按成员分别停止。
- 过程只在确认终态后自动收起，最终正文生成中不提前收起。工具详情沿用组件滚动锁；手动开合保留。正常 `outputsState=pending` 不再闪现补取按钮。
- 默认视图移除配置审计行和无归属的“本次参考”。配置与本轮提供的资料进入“更多 → 运行详情”；来源保存到 Hutian 请求快照，按成员恢复，保持与回答实际引用的区别。旧请求没有这份记录时不补造来源。
- 知识／记忆仍可在 `+` 菜单切换，不再伪装为具体附件。只有上传文件显示具体名称与移除操作。正文调整为 15px，工具原始命令留在详情；保存／交接等动作收进更多菜单。
- Matrix 宿主通过原任务目录的活动文件变化进行长轮询通知。Hutian SSE 单独推送有版本的运行活动，浏览器合并时拒绝旧版本覆盖新活动。每秒会话快照继续负责历史与状态核对，不再成为文字更新的唯一通路。没有假打字动画。
- 相邻同消息／同阶段公开文本增量合并保存，避免长回答仅因超过 300 个文字增量事件而丢失开头。原私有推理仍被过滤。
- 静态代理在上游流异常中止时关闭下游连接，使 EventSource 可以重连；离线恢复仍核对同一运行，不重新派发。
