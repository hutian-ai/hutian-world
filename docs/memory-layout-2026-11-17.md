# 记忆阅读布局修正（2026-11-17）

用户反馈记忆来源阅读区布局不合理。本轮沿用现有目录／原文工作面和主题，仅调整 Web 页面组合，不修改来源原文、记忆服务或资源授权。

- 阅读列最大 52rem，表格跟随阅读列；使用外框和行分隔线，减少单元格边框。
- 工作面适配剩余视口，目录与正文独立滚动；切换记录后正文回到顶部。
- 原文以同名一级／二级 Markdown 标题开头时，省略外层重复标题，保存内容不变。
- 目录与原文显示已有保存时间（Asia/Shanghai），方便区分同名记录；缺少时间不补造。
- 检索后选择目录记录直接回到原文；原文读取中有明确状态。
- 窄屏目录和正文分开显示，正文提供返回目录入口。知识库共用同一页面组件。

## 实际验证

已通过现有静态构建脚本更新本机前端，不重启 API 或执行宿主。使用真实数据在本机 Chrome 验证墨菲私有记忆、检索、目录切换、添加入口，以及个人知识库原文读取；没有写入验收记忆。

1440×1000、2560×1440 和 390×844 均无页面横向／纵向溢出；超宽屏正文保持 832px，窄屏长正文在阅读区内部滚动。截图中的配置记录仅保留一个标题，检索“本机配置”命中 3 条，目录切换能退出检索，切换记录后阅读区滚动归零。浏览器未观察到页面异常；本轮两份 TSX 的 ESLint 与 diff 空白检查通过。

Web 构建通过。整体 Web typecheck 最后一次仍被同时修改的 Runtime 详情页缺少 ObjectHeader 属性，以及 inbox-workspace 中的 scheduleReturnTo 名称错误阻塞；没有改动这些文件，也不宣称整仓类型检查已通过。
